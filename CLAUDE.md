# FEYA — правила работы с репозиторием

## Язык общения
- С владельцем проекта **всегда общаемся на русском языке** (ответы, отчёты, вопросы, описания PR).
- Промты могут приходить на русском или английском — отвечаем всё равно по-русски.
- Код, идентификаторы, имена коммитов и техническая документация (README, docs/) — на английском или русском по контексту,
  но пользовательские строки приложения обязаны быть локализованы (ru — по умолчанию, kk, en).

## Структура
- `backend/` — Spring Boot 3 (Java 21, Gradle, PostgreSQL, Flyway).
- `mobile/` — Flutter-приложение клиента (Riverpod, GoRouter, Dio).
- `docs/` — архитектура, API, деплой.
- Секреты не коммитим; конфигурация через переменные окружения (`.env.example`).
